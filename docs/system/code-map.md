# Planned code map

[Start here](../../README.md) · [Architecture](../../tracks/inference/ARCHITECTURE.md) · [Task index](../../tracks/inference/tasks/README.md)

This is the single design inventory for both tracks. It retains the original 88 source, test, configuration and environment responsibilities and adds the expanded agent boundaries. **These files do not currently exist.** The earlier comment-only files added clutter without executable behavior, so their responsibilities are kept here until implementation starts. Existing starter code and its original tests remain intact.

For a task, create only its needed files and focused tests. Concrete signatures, package/build metadata, runnable configurations and validated compatibility sets are still future work. Preserve the task's ownership and validation requirements. A proposed filename is not a frozen API or a reason to pre-create the entire tree.
